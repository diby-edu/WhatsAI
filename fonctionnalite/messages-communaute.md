## 2. ENGAGEMENT HEBDOMADAIRE

### Astuce semaine 1 — Pause bot
```
💡 Astuce WazzapAI #1

Savais-tu que tu peux mettre le bot en pause pour prendre la main manuellement sur une conversation ?

👉 Tableau de bord → Conversation → "Prendre le contrôle"

Le bot reprend automatiquement après 24h.

Utile quand un client a un problème délicat à gérer soi-même.
```

### Astuce semaine 2 — Statuts de commande
```
💡 Astuce WazzapAI #2

Les boutons de statut de commande sont tous visibles en même temps.

Pour une commande COD physique tu vois :
📦 Expédier   ✅ Livré   ❌ Annuler

Clique directement sur "Livré" si tu gères toi-même la remise — pas besoin de passer par "Expédier" d'abord.

Gain de temps garanti. ⏱️
```

### Astuce semaine 3 — Instructions IA
```
💡 Astuce WazzapAI #3

Tu peux donner des instructions spécifiques à ton agent pour chaque produit.

Exemple : "Si le client hésite, propose la version taille M en premier."

👉 Produits → Modifier → champ "Instructions IA"

Le bot suivra ces règles à la lettre pour ce produit uniquement.
```

### Astuce semaine 4 — Recherche admin
```
💡 Astuce WazzapAI #4

Dans le panneau admin, la recherche utilisateur fonctionne sur toutes les pages en même temps.

Tu peux chercher par :
· Nom
· Email
· Numéro de téléphone

Plus besoin de parcourir les pages une par une. 🔍
```

### Astuce semaine 5 — Catalogue vide
```
💡 Astuce WazzapAI #5

Si tu n'as pas encore configuré de produits, le bot le signale proprement au client :

"Désolé, aucun produit n'est configuré pour le moment. Revenez bientôt !"

Il n'invente rien. Tu peux donc connecter ton agent et tester sans risque même avant d'avoir ton catalogue complet.
```

### Astuce semaine 6 — Types de produits
```
💡 Astuce WazzapAI #6

WazzapAI gère 3 types de produits avec des flux différents :

📦 Physique → collecte adresse de livraison, suivi d'expédition
🎓 Service → collecte date/heure, confirmation de rendez-vous
💻 Numérique → livraison automatique du contenu après paiement

Configure le bon type pour chaque produit et le bot adapte son discours automatiquement.
```
